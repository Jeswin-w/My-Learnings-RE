# Computer-System Organization

## Big Picture
- A modern general-purpose computer system has:
	- One or more CPUs
	- Multiple device controllers
	- Shared memory
	- A common system bus connecting components

## Core Components
- CPU:
	- Executes instructions and coordinates system work.
- Device controller:
	- Manages a specific device type (disk, audio, graphics, USB, etc.).
	- Can handle one or many physical devices.
	- Example: one USB controller port can connect to a USB hub, and the hub can connect multiple devices.
- Shared memory:
	- Used by CPU and controllers; both compete for memory cycles.
- Memory controller:
	- Synchronizes and orders access to shared memory.

## Device Controller Internals
- Each controller has:
	- Local buffer storage
	- Special-purpose registers
- Main responsibility:
	- Move data between peripheral devices and its local buffer.

## Device Drivers (OS Role)
- The OS usually provides one device driver per device controller.
- A driver:
	- Understands controller-specific behavior.
	- Exposes a uniform interface to the rest of the OS.
- Benefit:
	- OS code can interact consistently with different hardware devices.

## Parallelism in the System
- CPU and device controllers can execute in parallel.
- They may contend for memory access.
- Ordered, safe memory access is enforced by the memory controller.

## Key Operating Concepts Introduced
- Interrupts:
	- Signal CPU about events that require attention.
- Storage structure:
	- How data is organized across memory/storage layers.
- I/O structure:
	- How the system performs input/output between devices and memory/CPU.

## Typical PC Example (from figure)
- Input/output devices: keyboard, mouse, monitor, printer, disks
- Controllers/adapters: disk controller, USB controller, graphics adapter
- CPU, memory, and controllers communicate over the system bus

## Quick Flow Summary
1. A device communicates with its controller.
2. The controller buffers/translates data.
3. Data moves via the system bus to or from shared memory.
4. CPU and controller coordinate through OS drivers and interrupts.
